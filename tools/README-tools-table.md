Replacement rows for the tools table in the workbench `README.md`. One row per route, in `ROUTE_LABEL` order (`src/partNav.js`), limited to the tool routes the current table covers. The former "Compliance readiness" row is split into DSA readiness and COPPA readiness; the former "AI assistants" row is split into Policy stress-tester, Enforcement notice writer, Appeal reviewer and Transparency report. Descriptions are reused from the current table and divided accordingly. Same column format as the current table.
